I'm an 8th-semester Software Engineering student at iCEV, in Teresina, Piauí, who enjoys turning ideas into working products — from React and Next.js interfaces to Python and Django backends and data pipelines. Beyond academics, I also take on freelance work: Python automations for web scraping and data collection, Power BI dashboards for data visualization, and full websites built end to end.
